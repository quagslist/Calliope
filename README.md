# Calliope

A Pinterest-inspired visual archive built with plain HTML, CSS and JavaScript.

## Run it

Open `index.html` in a browser.

## Publish it for free

Upload these files to a GitHub repository, then enable GitHub Pages in the repository's Settings → Pages.

The site currently uses public Unsplash image URLs for demo content. For a production version, replace those with your own images or a proper image-storage backend.
